# Wizard Next

Next.js project with React, TypeScript and Material UI.

## Requirements

- [Node.js](https://nodejs.org/) (v18 or higher recommended)

## Installation

```bash
git clone <repository-url>
cd wizard-next
npm install
```

## Running the project

**Development mode** (with hot reload):

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

**Production build:**

```bash
npm run build
```

**Run in production:**

```bash
npm start
```
